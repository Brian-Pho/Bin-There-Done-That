# Client

Vite + React UI for “Bin There, Done That.”

This first pass connects to the Socket.IO server, lets you set the grid dimension N, and shows received integers. The heatmap is not built yet.

## Run

1. Start the server (`cd ../server` then `npm start`)
2. `npm ci` (first time)
3. `npm start`

The app is at [http://localhost:3000/](http://localhost:3000/).
